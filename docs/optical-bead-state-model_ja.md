# 光学ビードの状態モデル

## 1. 状態ベクトル

光学ビードの状態は、光の自由度（DOF）ごとに一つずつの値を並べた組です。

```
B = (λ, P, φ, τ, w, s, ℓ)
```

このベクトルは、単一の光パルス、あるいは信号モードの、多次元の配置を表します。数を表すそろばんのビード配置と同じように、光学ビードの状態Bは、その多次元パターン全体を通じて、一つの情報記号を表します。

---

## 2. 自由度

### 2.1 波長（λ）

光学的な搬送波の波長、または周波数。実際には、スペクトルのチャネルに対応します。

- 離散化：利用可能なスペクトル範囲を、区別できるn_λ個の帯域に分ける。
- 実用上の制約：スペクトル線幅、フィルター帯域、ノイズを踏まえ、検出器が確実に区別できるよう、隣接するチャネルを十分に離す必要がある。
- 例：ダイオードレーザーによる、450 nm、532 nm、633 nm、780 nmの4水準。

### 2.2 偏光（P）

電場の振動の向きと楕円率。

- 一般的な離散状態：H（水平）、V（垂直）、D（斜め、+45°）、A（反斜め、−45°）、R（右円偏光）、L（左円偏光）。
- 実用上の制約：偏光の測定ノイズ、光学部品の複屈折、ファイバー内の偏波モード分散を踏まえ、偏光状態が区別できなければならない。
- 例：H、V、D、Aを用いた4水準。

### 2.3 位相（φ）

絶対的な、あるいは相対的な光の位相。

- 一般的な離散状態：4水準の位相アルファベットでは、0、π/2、π、3π/2。
- 実用上の制約：位相の測定には基準が必要である（干渉計による測定）。熱揺らぎによる位相の不安定性は、重大なノイズ源である。
- 近い将来の考慮：位相符号化は、古典的な試作にとって技術的に最も難しい自由度であり、後の試作段階に先送りされる可能性がある。

### 2.4 時間ビン（τ）

定められたフレーム窓の中の、離散的な時間ビンへの、光パルスの割り当て。

- 離散化：フレーム周期をn_τ個の時間ビンに分け、パルスはちょうど一つのビンに割り当てる。
- 実用上の制約：隣接するビンは、光源と検出器のタイミングジッタより大きく離す必要がある。
- 例：1 nsのパルスと200 ps未満のジッタを用い、10 nsのフレーム内に4つの時間ビン。

### 2.5 パルス幅（w）

光パルスの時間的な持続時間。

- 離散化：狭い、中間、広い（3水準）、あるいは時間分解能が良ければ、より細かく。
- 実用上の制約：検出器の帯域と、光学チャネルでの時間的な広がりを踏まえ、パルス幅が区別できなければならない。

### 2.6 空間モード（s）

横方向の空間プロファイル、あるいは光ビームの物理的な位置。

- 自由空間では：異なる空間位置、あるいは導波路のポート。
- ファイバーでは：マルチモードあるいは少数モードのファイバーの空間モード。
- 例：2×2の空間チャネルのアレイを用いた4つの空間位置。

### 2.7 軌道角運動量（ℓ）

光渦のトポロジカル・チャージで、らせん状の波面構造に対応します。

- 値：ℓ = 0（ガウシアン）、±1、±2、±3、…
- 実用上の制約：OAMモードの生成と検出には、専用の光学部品（スパイラル位相板、空間光変調器、qプレート）が必要。自由空間の伝搬では、大気の乱流がOAMモードを強く劣化させる。
- 近い将来の考慮：OAMは、制御された自由空間環境の実験室での試作には適するが、ファイバーベースの近い将来の試作にはあまり適さない。

## 3. アルファベットの定義

光学ビードのアルファベットは、互いに異なる状態ベクトルの有限集合です。

```
A = { B_0, B_1, B_2, ..., B_{N-1} }
```

ここで、各B_iは、各自由度への値の特定の割り当てです。

アルファベットは、試作の段階に応じて、利用可能なすべての自由度、あるいはその部分集合を用いることができます。

| 試作の段階 | 用いる自由度 | アルファベットの大きさの例 |
|---|---|---|
| 第1段階 | λ, P | 4 × 4 = 16状態 |
| 第1段階の拡張 | λ, P, τ | 4 × 4 × 4 = 64状態 |
| 第2段階 | λ, P, φ, τ | 4 × 4 × 4 × 4 = 256状態 |
| 第3段階（量子） | λ, P, φ, τ, ℓ | 4 × 4 × 4 × 4 × 4 = 理論上1024状態 |

**これらは理論上の上限です。**実用的なアルファベットの大きさは、目標とする精度のしきい値を超えて確実に復号できる、状態間の最小距離によって決まります。

---

## 4. 距離の尺度と最近傍復号

復号には、受信した（ノイズを含む）状態を、最も近いアルファベットの要素に割り当てるための、距離の尺度が必要です。

既定の尺度は、多次元の状態空間における、正規化したユークリッド距離です。

```
d(B_received, B_i) = sqrt( sum_j ( (B_received[j] - B_i[j]) / range_j )^2 )
```

ここで、range_jは自由度jの値の範囲で、各次元を[0, 1]に正規化するために用います。

デコーダは、次のように割り当てます。

```
B_decoded = argmin_{B_i in A} d(B_received, B_i)
```

B_decoded ≠ B_transmitted のとき、復号誤りが生じます。

---

## 5. 分離マージン

アルファベットの分離マージンは、互いに異なる任意の二つのアルファベットの要素の間の、最小距離です。

```
margin = min_{i ≠ j} d(B_i, B_j)
```

マージンが大きいほど、復号誤りが生じるまでのノイズへの許容度が大きくなります。臨界のノイズしきい値 — 復号精度が目標のしきい値を下回り始めるノイズ水準 — は、おおよそ margin / 2 に比例します。

アルファベットの設計は、実装の物理的な制約のもとで、最小のマージンを最大化すべきです。

---

## 6. アルファベットの例

### 最小の6状態アルファベット（第1段階の実現可能性の試験）

波長（3水準：450 nm、532 nm、633 nm）と偏光（2水準：H、V）を用います。

```
B_0 = (450 nm, H)
B_1 = (450 nm, V)
B_2 = (532 nm, H)
B_3 = (532 nm, V)
B_4 = (633 nm, H)
B_5 = (633 nm, V)
```

### 16状態のアルファベット

波長（4水準）と偏光（4水準）を用います。

```
B_(i,j) = (λ_i, P_j)  for i in {0,1,2,3}, j in {0,1,2,3}
```

### 符号化した数字（0〜9）

16状態のアルファベットから10状態を用い、6状態を予備／誤り符号とします。

```
digit 0 → B_(0,0) = (λ_0, P_0)
digit 1 → B_(0,1) = (λ_0, P_1)
...
digit 9 → B_(2,1) = (λ_2, P_1)
```
