# 密閉した液体の光学ビード媒質

[English Version](sealed-liquid-optical-bead-medium.md)

**所属：**[光学ビードコンピューティング](../README_ja.md)

## 概要

近い将来の古典的な光学ビードコンピューティングの試作機では、光源と検出器の間の光学チャネルが、開放空間の自由空間経路である必要はありません。密閉した透明な液体媒質 — 液浸で安定化した光学セル — は、ノイズとドリフトの複数の発生源を減らす、あるいはなくすことで、開放空間の構成と比べて、環境の安定性を高めるかもしれません。

この文書は、密閉した液体の光学ビード媒質の、構想、潜在的な利点、物理的な限界、シミュレーションモデル、試作機の設計上の考慮事項を説明します。

このアプローチは、量子コンピューティングへの一歩ではなく、**古典的な光学の試作機の設計上の選択**として理解するのが最も適切です。液体媒質が収めるのは、単一光子ではなく、巨視的な光パルスです。

---

## 1. 動機：開放空間と密閉した液体

開放空間の自由空間光学系は、次の擾乱を受けます。

| 擾乱 | 機構 | 光学ビード状態への影響 |
|---|---|---|
| 粉塵による汚染 | 粒子による散乱 | 振幅の減衰、ビームのステアリング |
| 湿度の変動 | 吸収帯、屈折率の変化 | 波長に依存した透過のドリフト |
| 空気の乱流 | 屈折率の揺らぎ（陽炎） | 波面の歪み、位相ノイズ |
| 機械的な振動 | ミラー／レンズの変位 | ビームの指向のドリフト、位相ノイズ |
| 熱膨張 | 光路長の変化 | 位相のドリフト |

密閉した液体の光学セルは、空気の隙間を、均質で密閉された透明な液体に置き換えることで、これらのほとんどに対処します。液体は：

- ビーム経路から、空気中の粉塵を取り除く
- 空気の乱流による屈折率の揺らぎを抑える
- 機械的に安定な媒質を提供する
- 光学窓の屈折率に整合させて、反射損失を減らせる

しかし、液体媒質には、固有の物理的な限界があります（第3節を参照）。

## 2. 提案する密閉液体セルのアーキテクチャ

最小の密閉した液体の光学ビード媒質は、次で構成されます。

```
[Source: laser/LED]
        |
        v
[Input window: anti-reflection coated glass]
        |
        v
[Liquid medium: transparent, refractive-index matched]
   ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
   - immersion oil, glycerol solution, water, or optical-grade liquid
   - temperature-controlled enclosure
   - sealed to prevent evaporation and contamination
   ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
        |
        v
[Output window: anti-reflection coated glass]
        |
        v
[Detector: color sensor, photodetector, spectrometer]
```

光学ビードの状態（波長、偏光、位相、時間ビン）は、セルに入る前に符号化され、検出器の後で復号されます。液体媒質は伝送チャネルにすぎず、符号化と復号のハードウェアは外部にあります。

### 液体媒質の選択

| 媒質 | 透過波長域 | 屈折率（概算） | 熱的な dn/dT | 備考 |
|---|---|---|---|---|
| 蒸留水 | 200 nm - 1300 nm | 1.333 | -1.0e-4 / K | 入手しやすい。中程度のdn/dT |
| グリセリン水溶液 | 200 nm - 1200 nm | 1.33 - 1.47（調整可能） | -2.5e-4 / K | 屈折率を濃度で調整できる |
| 液浸オイル（タイプA） | 400 nm - 800 nm | 1.515 | -3.0e-4 / K | 標準的な顕微鏡の液浸媒質 |
| 光学グレードのミネラルオイル | 400 nm - 1000 nm | 1.47 - 1.50 | -3.5e-4 / K | 低コスト。長期安定性にばらつきがある |
| フロリナート FC-770 | 250 nm - 2000 nm | 1.275 | -1.7e-4 / K | 紫外から赤外まで広い。高価。低毒性 |

媒質の選択は、使用する波長チャネル、必要な屈折率の整合、温度安定性の要件に左右されます。

## 3. 物理的な限界

### 3.1 吸収損失

すべての透明な液体は有限の吸収係数を持ち、伝搬経路に沿って光信号を減衰させます。

```
I(L) = I_0 * exp(-alpha * L)
```

ここで：
- `I_0` ＝ 入力強度
- `alpha` ＝ 吸収係数（m^-1 または cm^-1、波長に依存）
- `L` ＝ 経路長

短い実験室用のセル（L = 1-10 cm）では、適切に選んだ媒質での吸収損失は、通常小さい（< 1 dB）ものの、波長に依存します。これにより、波長に依存した信号の不均衡が生じ、多波長の光学ビード状態の復号に影響しうります。

### 3.2 気泡と不純物による散乱

微小な気泡、微粒子の不純物、溶存気体の放出は、散乱を引き起こし、それが：
- ビームの振幅を減衰させ
- ランダムな振幅の揺らぎをもたらし
- ビームの指向誤差を引き起こしうります。

防止には、慎重な液体の調製が必要です。脱気、ろ過（サブミクロン）、汚染のない充填です。特に熱サイクルの後は、ガスの放出による気泡の発生が、長期的な懸念です。

### 3.3 温度に依存した屈折率のドリフト

すべての液体は、ゼロでない熱光学係数dn/dTを持ちます（一般的な液体では、通常は負で、1ケルビンあたり-1e-4から-4e-4）。わずか1°Cの温度変化で、屈折率は1e-4から4e-4ずれます。

光学ビード状態への影響：
- **位相のずれ：**delta_n * L の光路長の変化は、(2*pi / lambda) * delta_n * L の位相のずれを生む。L = 5 cm、delta_n = 1e-4、lambda = 633 nm の場合：位相のずれは約0.05 rad で、位相符号化された状態にとっては大きい。
- **焦点距離のドリフト：**セルが結像あるいはコリメートの系の一部である場合、屈折率のずれが実効焦点距離を変える。
- **偏光：**窓ガラスの温度による応力複屈折が、偏光状態をわずかに回転させうる。

緩和には、経路長への慎重な配慮が必要です。L = 5 cm、lambda = 633 nm では、わずか0.1 Kの温度偏差が約5 radの位相ドリフトを引き起こし、位相符号化された状態を完全に乱すのに十分です。水の5 cmの経路長で0.1 rad未満の位相安定性を得るには、2 mKより良い温度制御が必要で、これは極低温並みの精度です。

**実用上の含意：**近い将来の液体媒質の試作機では、位相符号化を先送りすべきです。波長と偏光の符号化は、温度への感度がはるかに低く、第1段階の出発点となる自由度として推奨されます。位相符号化が必要な場合は、可能な限り短い経路長（< 1 mm）と能動的な干渉計による安定化を用いるか、固体の光学媒質に切り替えてください。

### 3.4 波長に依存した透過

どの液体も、すべての波長で完全に平坦な透過を持つわけではありません。水は970 nmと1200 nmの付近に吸収ピークがあります。液浸オイルは、近紫外に弱い吸収の特徴を持つことがあります。これにより、波長チャネル間で差のある減衰が生じ、光学ビードのアルファベットで使える波長水準の有効な数を減らしうります。

### 3.5 長期的な材料の劣化

有機液体は：
- 数か月から数年かけて酸化し、吸収を増やす（黄変）
- 気密に密閉されていなければ、大気中の水分を吸収し、屈折率を変える
- 化学的に安定化されていなければ、微生物の増殖を支える（水系の媒質）

ことがありえます。

フッ素系あるいはハロゲン系の光学液体（例：フロリナート）は、化学的により安定ですが、より高価です。

### 3.6 屈折率勾配による位相の不安定性

セル全体にわたる熱勾配は、空間的に不均一な屈折率をつくり、それが弱い勾配屈折率レンズとして働いて、ビームをゆっくりと傾け、焦点をぼかします。これは、バルクの温度ドリフトとは別のもので、壁だけでなく、セルの断面全体にわたる温度の均一性を必要とします。

## 4. ノイズモデルの拡張

液体媒質は、`simulator/noise_model.py`で用いている基本のガウスモデルを超える、ノイズ源をもたらします。`simulator/liquid_medium_noise.py`の拡張された液体媒質ノイズモデルは、次を加えます。

| ノイズ源 | モデル | パラメータ |
|---|---|---|
| 吸収による減衰 | `I(L) = I_0 * exp(-alpha * L)` | `alpha`, `L` |
| 散乱による振幅ノイズ | 振幅への乗法的な対数正規ノイズ | `sigma_scatter` |
| 温度に依存した位相ドリフト | 位相座標における、決定論的＋ゆっくりしたガウス型ドリフト | `dn_dT`, `delta_T`, `L` |
| 波長に依存した差のある減衰 | チャネルごとの利得のオフセット | `alpha_per_channel` |
| 熱勾配によるビームのステアリング | 空間座標における、ゆっくりしたガウス型の変位 | `gradient_sigma` |

これらは標準のガウスノイズモデルの上に適用され、液体媒質の光学ビードセルにおける信号劣化の、より現実的な（なお簡略化した）モデルを与えます。

## 5. 比較：開放空間と密閉した液体媒質

| 性質 | 開放空間 | 密閉した液体媒質 |
|---|---|---|
| 粉塵による汚染 | リスクあり（クリーンルームや筐体で制御） | なくなる（密閉） |
| 空気の乱流 | 室温で存在する | なくなる |
| 湿度の変動 | 存在する | なくなる（密閉） |
| 機械的なアライメントへの感度 | 高い | 中程度（液体が安定した機械的基準を与える） |
| 吸収損失 | ほぼゼロ（空気） | 小さいがゼロではない。波長に依存 |
| 位相の安定性 | 空気の乱流と熱膨張で制限される | 液体のdn/dTで制限される。温度調節で制御可能 |
| 気泡／不純物による散乱 | 低い（清浄な空気） | 液体が適切に調製されていないとリスクあり |
| アライメントの複雑さ | 高い（自由空間光学） | 中程度（窓を一度合わせればよい） |
| 長期的な安定性 | 筐体の品質に依存 | 液体の品質と封止に依存 |
| 屈折率の整合 | 該当なし（n_air ~ 1.00） | 窓ガラス（n ~ 1.5）に合わせて、反射を減らせる |
| 温度制御の要件 | 低い（空気はゆっくり安定する） | 中程度（液体のdn/dTには調節が必要） |

どちらのアプローチも、普遍的に優れているわけではありません。選択は、試作の環境、利用できる設備、符号化する対象の自由度に左右されます。

## 6. 推奨する近い将来の試作機の構成

波長と偏光のみを用いて、6〜24の光学ビード状態を目標とする、第1段階の密閉液体の試作機の場合：

**セルの設計：**
- ガラスのキュベット（標準的な分光用キュベット）、経路長10 mm
- 蒸留水、またはグリセリン水溶液（屈折率 ~1.40）で満たす
- PTFEコーティングのキャップ、または紫外線硬化の光学接着剤で密閉する
- 温度安定化したハウジングに取り付ける（ペルチェ素子、±0.1°Cの安定性）

**推奨する光源：**
- 450 nm、532 nm、633 nm、780 nmのダイオードレーザー（4つの波長チャネル）
- 反射防止コーティングされた、入出力の結合光学系

**偏光の符号化：**
- セルの入力窓の前に、ワイヤーグリッド偏光子
- 偏光解析のため、出力にキューブ型の偏光ビームスプリッター

**検出：**
- コンパクトなスペクトロメーター、またはマルチチャネルのカラーセンサー
- 時間ビンの符号化（使う場合）には、トリガー式のフォトディテクター

**開放空間のベースラインに対して期待される改善：**
- 位相の安定性：制御のない開放空間に対して、温度制御により約10倍の改善
- 振幅の安定性：約3倍の改善（乱流なし）
- 粉塵による振幅ノイズ：なくなる
- 正味の効果：ノイズモデルのσが下がり、同じ目標のSERで、より大きな実用的なアルファベットが可能になる

## 7. 限界のまとめ

密閉した液体のOBQCは、近い将来の**古典的な光学の試作アプローチ**であり、次の留意点があります。

- 収めるのは、巨視的な多光子の光パルスであり、単一光子ではない。
- 量子コヒーレンス、エンタングルメント、量子優位性を可能にするものではない。
- 安定性の改善は、決定論的な多値の光学符号化にとって意味があるが、量子光学コンピューティングとの隔たりを埋めるものではない。
- 液体媒質の劣化と気泡のリスクには、長期運用のための工学的な配慮が必要である。
- 温度制御は、ハードウェアの複雑さと消費電力を増やす。

これは、第1段階と第2段階の試作機の安定性を高めるための道具であり、フレームワークの根本的なアーキテクチャの変更ではありません。
