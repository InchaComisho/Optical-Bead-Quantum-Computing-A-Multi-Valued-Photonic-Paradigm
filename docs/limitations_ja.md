# 光学ビードコンピューティングの限界

[English Version](limitations.md)

## この文書の目的

限界を明確に述べることは弱みではなく、研究のフレームワークを信頼できるものにします。この文書は、光学ビードコンピューティング（OBC）のフレームワークの、既知の、そして予想される限界を、カテゴリーごとに整理して列挙します。

---

## 1. 根本的な物理的限界

### 1.1 ショットノイズ

あらゆる光学的な検出は、最終的にショットノイズ（光子計数の統計）を受けます。平均光子数nで検出された光パルスの信号対雑音比は、およそ sqrt(n) です。これは、測定の不確かさに対する根本的な下限を定め、工学的な改善では取り除けません。

低い光量（数光子のパルス）では、ショットノイズが、自由度ごとに区別できる状態の数を大きく制限します。

### 1.2 ハイゼンベルクの不確定性

位相と光子数は、共役な変数です。高い位相精度には、多くの光子数が必要で、これは、エネルギー効率の良い低電力の光学符号化という目標と相反します。これは工学的な問題ではなく、根本的なトレードオフです。

## 2. ノイズ源

| ノイズ源 | 説明 | 影響を受ける自由度 |
|---|---|---|
| 熱雑音 | 検出器の電子回路のジョンソン・ナイキストノイズ | すべて |
| ショットノイズ | 光子計数の統計 | すべて |
| レーザーの周波数ノイズ | 光源の線幅と周波数のジッタ | λ, φ |
| 位相ノイズ | 熱的・機械的な摂動による位相の揺らぎ | φ |
| 偏光の回転 | 部品とファイバーの複屈折 | P |
| タイミングジッタ | パルスの到着時刻の不確かさ | τ, w |
| 振幅ノイズ | 光源の強度の揺らぎ | すべて（強度符号化） |
| 暗計数 | 信号がないときの、検出器の誤検出 | すべて |

## 3. クロストーク

### 3.1 スペクトルのクロストーク

有限のスペクトル線幅を持つ波長チャネルは、隣接するチャネルと重なります。クロストークの電力は、おおよそ次のとおりです。

```
P_crosstalk ≈ exp( -(Δλ / σ_λ)^2 )
```

ここで、Δλはチャネル間隔、σ_λは光源の線幅です。クロストークを低くするには、チャネルを線幅の数倍だけ離す必要があります。

### 3.2 偏光のクロストーク

不完全な偏光子や複屈折性の光学素子は、偏光状態を回転させたり混ぜたりします。典型的な偏光光学部品の偏光消光比（PER）は20〜40 dBで、実際に区別できる偏光状態の数は2〜4に制限されます。

### 3.3 位相のクロストーク

位相状態は、位相ノイズのRMSより大きく離す必要があります。室温の典型的な自由空間の光路では、位相の揺らぎは、経路長に応じて、数十ミリラジアンからラジアン単位に及びます。能動的なフィードバックによる安定化は可能ですが、複雑さが増します。

### 3.4 OAMモードのクロストーク

OAMモードは、理想的な自由空間の条件では直交しますが、大気の乱流、ビームのずれ、開口による切り捨てのもとでは、大きなクロストークを受けます。ファイバーでは、OAMモードは、曲がりや不完全さのところで、他の空間モードと結合します。

## 4. 較正とドリフト

### 4.1 較正の要件

光学ビードのアルファベットは、較正の基準に対して定義されます。次のいずれかにドリフトがあると：
- 光源の波長または強度
- 偏光の基準系
- 位相の基準経路
- タイミングの基準

系統的なずれが生じ、送信された状態が隣接するアルファベットの要素に近づき、誤り率が増えます。

### 4.2 ドリフトの発生源

| ドリフトの発生源 | 時間スケール | 影響 |
|---|---|---|
| 熱膨張 | 数分から数時間 | 位相、アライメント |
| 機械的な振動 | ミリ秒から秒 | 位相、OAM、アライメント |
| 部品の経年劣化 | 数か月から数年 | 波長、偏光 |
| 環境の湿度 | 数時間から数日 | 位相（吸湿性の光学部品） |
| レーザーの経年劣化 | 数か月から数年 | 波長の安定性 |

実用的なシステムには、定期的な再較正が必要です。長期的な自律運転には、能動的な安定化のフィードバックが必要です。

## 5. スケーラビリティ

### 5.1 状態数と実用的なアルファベットの大きさ

理論上の状態数は、自由度の数に応じて、乗算的に増えます。

```
N_theoretical = n_λ × n_P × n_φ × n_τ × n_w × n_s × n_ℓ
```

しかし、アルファベットの大きさが増えると、（物理空間を固定した場合）状態間の最小距離が減り、ノイズによる復号誤りが増えます。実用的なアルファベットの大きさは、全次元にわたる最悪の場合のノイズフロアによって制約されます。

自由度を増やすと、新たなクロストークの機構が生じます。各自由度を追加することの限界的な利益は、増える複雑さと、新たな誤り源と比べて、考える必要があります。

### 5.2 ハードウェアの複雑さ

各自由度には、専用のハードウェアが必要です。
- 波長：波長可変光源、またはフィルターバンク
- 偏光：偏光光学部品、波長板
- 位相：位相変調器、干渉計の基準
- 時間ビン：高速変調器、タイミング用の電子回路
- 空間モード：空間光変調器、または導波路アレイ
- OAM：スパイラル位相板、または空間光変調器

5つの自由度を同時に使うシステムには、上記のハードウェアのすべてが、精密に位置合わせされ、安定化されて必要です。これは研究室では実現可能ですが、管理された環境の外で拡大したり展開したりするのは困難です。

## 6. 既存技術との比較

実験的な証拠なしに、OBQCを既存の技術の代替として位置づけるべきではありません。関連する比較：

| 技術 | 成熟度 | OBQCに対する関連する利点 |
|---|---|---|
| 二進のデジタルコンピューティング | 成熟し、高度に最適化されている | 数十年にわたる最適化、ソフトウェアのエコシステム、規模での誤りのない動作 |
| 光通信（WDM） | 成熟 | 産業グレードの波長多重がすでに展開されている |
| 高度な変調（QAM） | 成熟 | 通信における高いスペクトル効率、標準化されている |
| GPU／TPUの並列コンピューティング | 成熟 | AIワークロードのための、大規模並列のデジタル計算 |
| クディット量子コンピューティング | 初期の研究 | 真の量子優位性の可能性。OBQCの第3層は関連する |

OBQCがこれらの技術に対して優位性を持つという主張は、特定のワークロードについての、未解決の研究仮説であり、実証された事実ではありません。

## 7. 理論と実践のギャップ

最も重要な限界を、明確に述べます。

> 光学ビードシステムの理論上の状態数は、常に、実用的に使えるアルファベットよりはるかに大きい。

4波長 × 4偏光 × 4位相 × 4時間ビンのシステムは、N_theoretical = 256状態です。実験室の試作機の現実的なノイズ条件のもとで、SER 5%未満で復号できる実用的なアルファベットは、ノイズフロアに応じて、16、32、あるいは64状態かもしれません。

このギャップはフレームワークの失敗ではなく、測定すべき鍵となる実験量です。シミュレーターと試作機のロードマップの目的は、現実的な条件のもとで、このギャップを特徴づけることです。

## 7. 光学媒質の限界

光学チャネルの媒質の選択は、開放空間の自由空間経路の限界に加えて、さらなる限界をもたらします。関連：[docs/optical-medium-stabilization_ja.md](optical-medium-stabilization_ja.md)。

### 7.1 液体媒質

| 限界 | 影響 |
|---|---|
| 吸収損失 | 波長に依存した信号の減衰。チャネル間での利得の差 |
| 気泡による散乱 | ランダムな振幅の低下。脱気と密閉容器が必要 |
| 熱による屈折率のドリフト | 水では dn/dT ~ -1e-4 /K。経路長5 cmで、0.1 Kにより約5 radの位相のずれ |
| 長期的な汚染 | 容器の材料からの溶出。水の中での微生物の増殖 |
| 液体の対流 | 熱勾配が、ゆっくりした屈折率の揺らぎを駆動する |

**位相符号化にとっての重大な限界：**センチメートル規模の経路長では、液体媒質は、位相の安定性のために、サブミリケルビンの温度制御を必要とします。位相の自由度は、より短い経路、あるいは固体媒質の実装に先送りすべきです。

### 7.2 固体ポリマー媒質（アクリル／光学樹脂）

| 限界 | 影響 |
|---|---|
| 応力複屈折 | 硬化と機械加工の応力が偏光状態を回転させ、偏光の自由度を劣化させる |
| 閉じ込められた気泡 | 鋳造したポリマーには、硬化の過程で微小な空隙が含まれうる |
| 硬化収縮 | 重合中の体積収縮が、内部応力を生む |
| 熱膨張 | PMMAの熱膨張係数は約70 ppm/K（ガラスは約3 ppm/K）。温度による光路長の変化が大きい |
| 長期的な黄変 | 一部のアクリルのグレードでは、紫外線の吸収が時間とともに増える |

**重要な含意：**アクリル／PMMAのブロックは、波長、強度、空間位置の符号化には適しますが、複屈折と熱膨張係数の影響を特性評価せずに、偏光や位相の自由度に用いることは推奨されません。

### 7.3 光学ガラス、石英、ファイバー

これらの材料は、ポリマーの代替に比べて、応力複屈折がはるかに低く、熱膨張係数が低く、光学的な均質性が優れています。しかし：
- ガラスや石英のブロックは、精密な機械加工あるいは成形を必要とし、製作コストが高い
- ファイバーの結合には、精密なマイクロ光学のアライメントが必要で、結合損失が実用上の懸念である
- 標準的なSMFのファイバー複屈折は、温度と曲げに伴って蓄積する。安定した偏光符号化には、偏波保持ファイバー（PMF）を用いる

### 7.4 量子光学への拡張

第3段階の量子光学への拡張では、あらゆる媒質への要求が、大幅に厳しくなります。
- 単一光子の損失予算はきわめて厳しく、1 dBの損失でも、量子状態の忠実度を大きく下げる
- 気泡、介在物、材料の不均質性によるレイリー散乱は、単一光子の状態の純度を壊す
- 位相コヒーレンスを、経路長の全体にわたって保たなければならない。確率的な位相の揺らぎは、量子干渉を劣化させる
- 液体セルやポリマーブロックは、相当な工学的努力なしには、単一光子の量子光学実験に適さない
- 量子OBQCの拡張に適した媒質は、ファイバー（低損失のSMFまたはPMF）、あるいはフォトニック集積回路である

## 8. ハイブリッド量子支援の限界

この節は、OBQCがハイブリッド量子コンピューティングシステムにおける補助的なパターン認識層として機能しうる、という仮説に固有の限界を扱います。関連：[docs/hybrid-quantum-support-layer_ja.md](hybrid-quantum-support-layer_ja.md)。

### 8.1 OBQCは極低温冷却をなくさない

超伝導量子ビットは、量子コヒーレンスを保つために、約20 mK以下での動作を必要とします。これは、室温の熱揺らぎに対する超伝導回路の構成要素のエネルギースケールによって決まる、根本的な物理的要件です（300 KでのkTは約26 meV。トランズモンの量子ビット遷移エネルギーは通常5-10 GHzで、20-40 ueVに相当）。光学的な補助層は、これを変えません。

OBQCが量子コンピューティングの冷却の問題を「解決する」という提案は、誤りです。正しい位置づけは、OBQCが、なお極低温冷却を必要とする量子システムの周りの、補助的な処理のオーバーヘッドを減らしうる、ということです。

### 8.2 補助エネルギーは、システム全体のエネルギーの小さな一部かもしれない

現在の超伝導量子コンピュータでは、極低温のインフラ（希釈冷凍機）が10-30 kWの電力を消費します。室温の電子回路は1-5 kWを消費するかもしれません。OBQCが補助的な電子回路のエネルギーを20-50%削減しても、システム全体のエネルギーの節約は、極低温設備に比べて、わずかです。

規模が大きくなる（数百万量子ビット）と、制御・読み出しのインフラが増えるにつれて、バランスが変わるかもしれませんが、これはハードウェアレベルでの確認を必要とする仮説のままです。

### 8.3 インターフェースの変換コストが、利益を消すかもしれない

ハイブリッド量子システムは、複数の信号領域にまたがって動作します。ミリケルビンでの量子マイクロ波信号、4 Kでの増幅されたRF、室温のデジタル電子回路、そして場合によっては光信号です。領域間の変換のたびに：
- エネルギーのコスト（変換用の電子回路、レーザードライバー、検出器）
- 信号の忠実度の損失（各段階で加わるノイズ）
- 遅延（伝搬、検出器の積分時間）

が生じます。

光学的なパターン認識の利益は、境界での変換のオーバーヘッドによって、部分的に、あるいは完全に消されるかもしれません。これは仮定するのではなく、実際のハードウェアで測定しなければなりません。

### 8.4 実時間の遅延の制約

量子誤り訂正は、通常、厳しい遅延の要件のもとで動作します。物理ゲート時間が約100 ns、符号サイクル時間が約1 usの表面符号では、古典的なデコーダは、計算に遅れないよう、この時間窓の中でシンドローム解析を完了しなければなりません。光学的なアナログ処理は、次による追加の遅延をもたらします。
- 光学的な伝搬時間
- 検出器の積分とリセットの時間
- 分類器の出力のアナログ・デジタル変換

OBQC的な処理が、実際のシステムでこれらのタイミング要件を満たせるかどうかは、実証されていません。

### 8.5 ベンチマークのデータは存在しない

光学的なパターン認識層が、実際の量子コンピューティングシステムで補助エネルギーを減らすことを示した実験は、ありません。このフレームワークのすべての主張は、簡略化した仮定に基づく、モデルレベルの仮説です。このリポジトリの簡易モデル（`hybrid_quantum_support_energy.py`、`pattern_vs_binary_operation_cost.py`）は、仮説を組み立てるための出発点であり、仮説の証拠ではありません。

### 8.6 量子優位性は主張しない

OBQCは、古典的な多値の光学符号化フレームワークです。量子的な高速化、量子優位性、あるいは量子コヒーレンスやエンタングルメントを必要とする計算上の利益は、提供しません。量子的な構成要素ではなく、古典的な補助層として提案されています。

- 物理的な光学ビードの試作機は作られていない。
