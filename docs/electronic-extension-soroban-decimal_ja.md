# 電子的な拡張：そろばん符号化の十進論理

[English Version](electronic-extension-soroban-decimal.md)

**所属：**[光学ビードコンピューティング](../README_ja.md)

## 概要

光学ビードコンピューティングは、そろばんに着想を得た多次元の光学パターンとして、情報を符号化します。同じそろばんの構造論理は、電子回路にも対応づけることができ、十進数の桁の、補完的な電子的表現を与えます。

この文書は、**そろばん符号化十進（Soroban-Coded Decimal：SCD）**論理を説明します。これは、そろばんの一本の軸の物理的な構造を、デジタルハードウェアで写し取った、5ビットの制約付き十進セルです。

---

## 1. そろばんの十進セル

そろばんの一本の軸は、二種類の珠を用いて、0から9の十進の桁を表します。

- **上の1つの珠（五珠）：**有効なとき、値は5
- **下の4つの珠（一珠）：**有効なとき、それぞれ値は1

桁の値は、次のとおりです。

```
digit = 5 * H + count(L1, L2, L3, L4)
```

これは、5ビットのデジタルセルに自然に対応します。

```
D = (H, L1, L2, L3, L4)
```

ここで、H ∈ {0, 1}、各Li ∈ {0, 1} です。

---

## 2. 温度計符号の下の珠

一意で、視覚的に解釈でき、誤りを検出できる符号化のために、4つの下の珠は**温度計符号**を用います。下の珠は、右から左へ順に、隙間なく有効になります。

有効な下の珠のパターンは、連続したブロックをなします。

```
count = 0  →  L = 0000
count = 1  →  L = 0001
count = 2  →  L = 0011
count = 3  →  L = 0111
count = 4  →  L = 1111
```

これにより、有効な下の状態が5通り × 上の状態が2通り ＝ 10通りの、有効な桁の符号が得られます。

---

## 3. SCD符号化の完全な表

| 十進 | H | L4 | L3 | L2 | L1 | 5ビット符号 |
|---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 0 | 0 | 0 | 0 | 0 | 0 | `0 0000` |
| 1 | 0 | 0 | 0 | 0 | 1 | `0 0001` |
| 2 | 0 | 0 | 0 | 1 | 1 | `0 0011` |
| 3 | 0 | 0 | 1 | 1 | 1 | `0 0111` |
| 4 | 0 | 1 | 1 | 1 | 1 | `0 1111` |
| 5 | 1 | 0 | 0 | 0 | 0 | `1 0000` |
| 6 | 1 | 0 | 0 | 0 | 1 | `1 0001` |
| 7 | 1 | 0 | 0 | 1 | 1 | `1 0011` |
| 8 | 1 | 0 | 1 | 1 | 1 | `1 0111` |
| 9 | 1 | 1 | 1 | 1 | 1 | `1 1111` |

2^5 = 32通りの5ビットのパターンのうち、有効なのは10通りだけです。22通りの無効なパターンは、検出可能な誤り状態として機能します。

---

## 4. 構造上の性質

### 4.1 直接的な十進表現

各SCDセルは、ちょうど一つの十進の桁を保持します。保存されたビットパターンとその十進の値の間に、暗黙の変換ステップはありません。これは、次と対照的です。

- **二進化十進（BCD）：**4ビットの符号で、そろばんとの構造上の対応はない
- **標準的な二進：**十進で出力するには、複数桁の変換が必要
- **SCD：**ビットパターンが、物理的な珠の位置を直接写し取る

### 4.2 桁上がりと桁借りの構造

セルに**1を加える**場合：
- 下の個数 < 4 の場合：下の個数を増やす（次のLビットを有効にする）
- 下の個数 = 4 かつ H = 0 の場合：下を0000にリセットし、H = 1 にする（そろばんの「5の補数による繰り上げ」）
- 下の個数 = 4 かつ H = 1 の場合：すべてを0000にリセットし、次の上位セルへ桁上がりを生成する

これは、物理的なそろばんの機械的な桁上がりの論理に、よく合致します。桁上がりでは、五珠を動かし、一珠をリセットします。

### 4.3 1の減算（桁借りの構造）

- 下の個数 > 0 の場合：下の個数を減らす
- 下の個数 = 0 かつ H = 1 の場合：下を1111（＝4）にし、Hをクリアする（5のグループからの桁借り）
- 下の個数 = 0 かつ H = 0 の場合：すべてを1111 1（＝9）にし、次のセルから桁借りを生成する

これも、そろばんの桁借りの仕組みを写し取っています。

### 4.4 誤りの検出

有効な10通りの集合にない5ビットのパターンは、不正な状態です。簡単な妥当性の検査は、次のとおりです。

```
valid(D) = True iff
  lower_count(L) in {0,1,2,3,4}   AND
  lower_is_thermometer(L)
```

ここで、`lower_is_thermometer`は、下のビットが連続したブロックをなす（隙間がない）ことを確認します。無効な状態は、追加のパリティビットなしに、検出して印をつけられます。

## 5. 既存の十進符号化との比較

| 符号化 | 1桁あたりのビット数 | 有効なパターン | 誤りの検出 | そろばんの構造 |
|---|---|---|---|---|
| **SCD（この提案）** | 5 | 10 / 32 | あり（22の無効状態） | 直接的 |
| BCD（8421） | 4 | 10 / 16 | 部分的（6の無効状態） | なし |
| 3増しコード | 4 | 10 / 16 | 部分的 | なし |
| 2-of-5コード | 5 | 10 / 32 | あり（22の無効） | なし |
| グレイコード十進 | 4 | 10 / 16 | 部分的 | なし |

SCDは、2-of-5コードと同じビット数を使いますが、そろばんの論理に由来する、構造上の動機を持つ符号化です。

**注記：**SCDは、保存密度でコンパクトな符号化と競うことを意図していません。その価値は構造的なものです。そろばんの珠の論理をシリコンに写し取ることで、このフレームワークの中の、フォトニック、電子的、認知的なモデルの間の、自然な橋渡しになります。

## 6. 複数桁の数

複数桁の十進数は、十進の桁ごとに一つの、SCDセルの配列として表されます。

```
N-digit number:  [ D_{n-1}, D_{n-2}, ..., D_1, D_0 ]
                   most significant       least significant

Each D_i = (H_i, L4_i, L3_i, L2_i, L1_i)
```

これは、各軸が独立して一つの桁を保持する、そろばんの複数軸の配置に対応します。

4桁の数（0〜9999）では、4 × 5 = 合計20ビットになり、次と比べられます。

- BCD：16ビット（よりコンパクトだが、そろばんの構造はない）
- 二進：最小14ビット（最もコンパクトだが、十進の構造はない）

## 7. 光学ビードコンピューティングとの関係

SCD符号化は、OBQCフレームワークにおける光学ビード状態の、**電子的な類似物**です。

| 領域 | 情報の単位 | 自由度1 | 自由度2 | 有効な状態 |
|---|---|---|---|---|
| そろばん（物理） | 一本の軸の上の珠の配置 | 五珠 H | 一珠 L1–L4（温度計符号） | 10 |
| SCD（電子） | 5ビットの十進セル | Hビット | L1–L4ビット（温度計符号） | 32のうち10 |
| OBC（光学） | 光学ビードの状態B | λ, P, φ, ... | 多自由度の符号化 | アルファベットで定義 |

三つの表現はいずれも、同じ構造上の原理を共有します。**値は、線形の二進の並びではなく、多成分のパターンである。**

この整合により、三つの領域は次を共有できます。

- 符号化表の構造
- パターンに基づく演算の論理
- 無効状態の検査による誤りの検出

## 8. ハードウェア実装の注記

### 妥当性検査器（組み合わせ論理）

```
valid(H, L4, L3, L2, L1) =
  NOT (L3 AND NOT L4)  -- no gap: L3 can only be 1 if L4 is 1
  AND NOT (L2 AND NOT L3)
  AND NOT (L1 AND NOT L2)
```

これは、AND 3個 + NOT 3個 + AND 2個を必要とする、5入力の組み合わせ回路です。

### 1の加算（順序論理のスケッチ）

```
carry_out = H AND (L4 AND L3 AND L2 AND L1)

if NOT carry_out:
    if L4 AND L3 AND L2 AND L1:
        -- lower full, H = 0 → set H = 1, clear lower
        H' = 1, L' = 0000
    else:
        -- activate next lower bead
        L'[i] = first 0 from right set to 1
        H' = H
else:
    -- overflow: reset to 0, carry to next cell
    H' = 0, L' = 0000
```

### FPGA／ASICへの適性

SCD論理は、FPGAのLUTやASICの標準セルで、簡単に実装できます。セルが広い（BCDの4ビットに対して5ビット）ことは、より単純な桁上がりの論理と、組み込みの誤り検出で相殺されます。

## 10. 限界と未解決の問い

- **面積のコスト：**1桁あたり5ビットは、BCDの4ビットに比べ、1桁あたりの記憶が25%多い。
- **ツールチェーンの対応：**SCD用の標準的なCADツールのライブラリは存在せず、独自のセル定義が必要。
- **速度：**そろばん構造の桁上がり連鎖が、最適化された二進加算器より速いとは限らず、ベンチマークが必要。
- **用途の範囲：**SCDは、特定のパターン指向の十進の応用に適するものであり、汎用の算術の置き換えではない。
- **シリコンの試作なし：**2026-06-03時点で、SCDは、製造されたハードウェア実装のない、提案段階の論理モデルである。
