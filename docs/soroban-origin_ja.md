## 1. そろばん

そろばんは、算術計算に用いられる日本の計算道具です。長方形の枠に垂直な軸が並び、それぞれの軸に5つの可動なビード（珠）があります。横の梁の上に1つの*五珠*（5を表す）、梁の下に4つの*一珠*（それぞれ1を表す）です。

0から9の数は、梁の側に寄せられた珠の配置によって、1本の軸で表されます。

| 値 | 梁に寄せた一珠 | 梁に寄せた五珠 |
|---|---|---|
| 0 | 0 | なし |
| 1 | 1 | なし |
| 2 | 2 | なし |
| 3 | 3 | なし |
| 4 | 4 | なし |
| 5 | 0 | あり |
| 6 | 1 | あり |
| 7 | 2 | あり |
| 8 | 3 | あり |
| 9 | 4 | あり |

複数桁の数は、すべての軸にわたる、同時のビード配置として符号化されます。熟練者は、各軸を順番に読むのではなく、空間パターンの全体を一度に知覚し、操作します。

この*パターン全体*による表現が、光学ビードコンピューティングの基礎となる類比です。

---

## 2. フラッシュ暗算

フラッシュ暗算（*flash mental arithmetic*）は、一連の数を、画面に極めて高速（ときに1つあたり0.2秒）で表示し、実践者がその累計を暗算で求める訓練です。

上級者は、3桁の数を10個以上、各0.2秒で表示した数列でも、正確な結果を出します。これは、意識的に記号を1つずつ計算する方法では説明できない、計算のスループットです。

熟練したフラッシュ暗算の実践者についての研究は、次のことを示唆しています。

1. **脳内のそろばんのシミュレーション：**熟練者は、数字の記号を処理するのではなく、そろばんを思い浮かべ、*珠を動かしている*と報告します。
2. **空間パターンの操作：**演算は、抽象的な数値の表現ではなく、空間的なビードの像の上で行われます。
3. **右脳の関与：**神経画像の研究は、記号的な算術の回路により頼る初心者と比べて、空間・視空間の処理領域がより多く関与することを示唆しています。

重要な含意は、そろばんの表現を介すると、数値の加算が、記号的な規則の適用ではなく、*空間パターンの変換*になる、ということです。

## 3. そろばんのパターンから光学ビードのパターンへ

光学ビードコンピューティング（OBC）は、そろばんの類比を、軸の上の物理的な珠から、光の自由度にわたる光学状態へと拡張します。

対応は次のとおりです。

| そろばん | 光学ビードコンピューティング |
|---|---|
| 物理的な軸 | 光の一つの自由度（例：波長軸） |
| 軸の上の珠 | 一つの自由度の中の、離散的な状態 |
| 珠の位置（上／下／個数） | その自由度の中の状態の水準（例：450 nm／532 nm／633 nm） |
| すべての軸にわたる珠の配置全体 | 光学ビードの状態ベクトル B = (λ, P, φ, τ, w, s, ℓ) |
| そろばんの算術演算 | 光学状態の変換 |
| フラッシュ暗算における視覚的なパターン認識 | 多次元の光学状態の復号 |

この類比は、構造上の原理をとらえています。**情報の単位は、単一の二値ではなく、全体のパターンとして符号化され、変換され、認識される、構造化された多次元の配置である。**

---

## 4. なぜパターンの論理が重要なのか

二値のコンピューティングでは、記号は0か1のどちらかです。数を表すには、複数の二値記号を連結します。各記号は、他の記号との構造的な関係を持たず、意味は位置の並びにあります。

そろばんの表現では、構造的な配置は本来的に空間的で多値です。「数字の7」は3つのビットの並びではなく、特定の空間的な配置（2つの一珠と1つの五珠）であり、実践者はそれをひとつのゲシュタルトとして知覚します。

OBQCを動機づける仮説は、この構造的な違い — 単位としてのパターンと、記号の並び — が、光学系に移されたときに、計算上の含意を持ちうるかもしれない、というものです。具体的には：

- 多次元の光学状態は、一回の測定事象に、より多くの情報を詰め込めるかもしれない。
- パターンに基づく復号は、ある種のノイズに対して頑健かもしれない（たとえば、パターン全体がずれても、他のすべてのパターンと区別できるままである場合）。
- 構造的にパターン的な課題（認識、分類、検索）では、光学ビードの表現が、課題の構造により自然に対応するかもしれない。

これらの仮説は証明されていません。OBQCが調べるために設計された、研究上の問いを定めるものです。

---

## 5. この類比が主張しないこと

そろばんから光学ビードへの類比は、概念的・構造的な動機づけです。次のことを意味しません。

- 光学ビードコンピューティングが、人間の暗算と同等であること。
- 神経のパターン処理を再現すること。
- 熟練したフラッシュ暗算の実践者の速度や正確さを、自動的に達成すること。
- この類比が、何らかの計算上の優位性を証明すること。

この類比は*設計原理*です。情報を二値の並びではなく、多次元のパターンとして構造化し、この構造がどのような計算課題を効果的に支えるかを探ることです。
